# Справочник Python (русская версия)

Откройте `index.html` в браузере — сервер не нужен.

## Структура
- `index.html` — разметка страницы
- `css/style.css` — оформление (тёмная и светлая темы, адаптив для телефона)
- `js/data.js` — **всё содержимое справочника** (ключевые слова, функции, типы, модули)
- `js/app.js` — логика: запуск Python, поиск, прогресс, карточки, викторина, песочница

## Как добавить своё понятие
Откройте `js/data.js`, найдите нужный раздел и допишите строку в `items`:

    ["имя", "описание", c`код примера`, "Важно знать", уровень, { опции }]

Уровень: 1 — основы, 2 — дальше, 3 — продвинутое.
Опции (необязательно): `stdin: "ответ для input()"`, `err: true` (если пример должен завершаться ошибкой).
В тексте можно выделять `код` обратными кавычками. Счётчики на странице пересчитаются сами.

## Что нужно для работы
- Интернет при первом запуске примера: Python (Pyodide, около 10 МБ) загружается с cdn.jsdelivr.net и кешируется браузером.
- Шрифты подтягиваются с Google Fonts; без интернета подставятся системные.
- Прогресс хранится в localStorage браузера на этом устройстве.
